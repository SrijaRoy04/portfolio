# Srija Roy - Personal Portfolio

Welcome to my personal portfolio website! This project is a fully responsive Single Page Application (SPA) built using modern web development technologies. It showcases my skills, experience, and projects.

## 🚀 Technologies Used

- **React 18** - Component-driven UI development
- **Vite** - Lightning fast development environment and bundler
- **Tailwind CSS** - Utility-first styling and responsive design
- **React Router (v6)** - Client-side routing

## 🛠️ Project Features

- **Responsive Design**: Uses Tailwind CSS breakpoints (e.g., `sm:`, `md:`, `lg:`) to ensure optimal viewing across desktops, tablets, and mobile devices.
- **External CSS**: Uses external stylesheets (`src/index.css`, `src/App.css`) along with Tailwind for clean, modular styling.
- **Pure JSX**: The UI structure is completely built with React functional components using JSX.

## 📁 Directory Structure

```text
├── public/                 # Static assets (images, icons)
├── src/                    
│   ├── components/         # Reusable UI components (Navbar, Footer)
│   ├── pages/              # Main page views (AboutMe, Contact, etc.)
│   ├── App.jsx             # Main routing layout
│   ├── App.css             # External custom CSS
│   ├── index.css           # Global styles and Tailwind imports
│   └── main.jsx            # Application entry point
├── package.json            # Project dependencies and scripts
├── tailwind.config.js      # Tailwind CSS configuration
└── vite.config.js          # Vite configuration
```

## ⚙️ Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Open your terminal and navigate to the project directory:
   ```bash
   cd Assignment1_Portfolio
   ```

2. Install the required dependencies:
   ```bash
   npm install
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to the URL provided in the terminal (usually `http://localhost:5173`) to view the application locally!
