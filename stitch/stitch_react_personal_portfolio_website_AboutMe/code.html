// journey.log • updated 2024

I began my engineering career hacking on custom Linux kernels and writing network packet analyzers before falling in love with the immediate feedback loop of modern web frontends. That dual perspective shapes how I operate: I treat browser memory with the same rigor as microservice clusters.
